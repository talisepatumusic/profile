# Talisepatu Music - Website

Website profil band wedding dan event. Satu halaman statis (HTML, CSS, JS), tanpa proses build.

## Isi folder
- `index.html` halaman utama
- `images/` logo dan semua foto
- `video/hero.mp4` video latar bagian home (tanpa suara)

## Cara pasang di GitHub Pages
1. Buat repository baru di GitHub, lalu unggah semua isi folder ini (index.html harus ada di bagian paling atas repository).
2. Buka Settings, lalu Pages.
3. Pada Source pilih "Deploy from a branch", branch `main`, folder `/ (root)`, lalu Save.
4. Tunggu beberapa menit. Alamatnya biasanya `https://NAMA-AKUN.github.io/NAMA-REPOSITORY/`.

## Catatan
- Font (Cormorant Garamond dan Quicksand) dimuat dari Google Fonts, jadi butuh internet.
- Kalau mengunggah lewat browser, batasnya sekitar 25 MB per file. Semua file di sini jauh di bawah itu.
